## Steps on How to Create a GitHub Page

1. Create a new repository.
2. Add the website files, including the HTML, CSS, and image files, to the repository.
3. Organize the files properly into their appropriate folders.
4. Commit and save the changes to the repository.
5. Go to the repository's Settings.
6. Navigate to the Pages section.
7. Select the main branch as the deployment source.
8. Save the settings and wait for GitHub Pages to deploy the website.
9. Open the generated GitHub Pages link to view the live website.
